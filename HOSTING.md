# 🚀 Help Funpay by yasha — запуск на BotHost (и любом хостинге без консоли)

Это форк [PaltoFunPayBot](https://github.com/PaltoProjects/PaltoFunPayBot) от PaltoProjects,
доработанный для хостинга. Что изменено относительно оригинала:

| Что | Зачем |
|---|---|
| Настройка через **переменные окружения** (`utils/env_config.py`) | На хостинге нет консоли, а оригинал при первом запуске просит ввести токен с клавиатуры. Без этой правки бот там просто не стартует |
| **Сторож** в `main.py` | `python main.py` запускает бота дочерним процессом. Если бот упал (ошибка, сеть, сбой FunPay), сторож поднимает его снова через 5, 10, 20 … 120 секунд |
| **Watchdog потоков FunPay** (`core/funpay_client.py`) | В оригинале при падении потока FunPay Telegram-меню продолжало работать, а заказы и сообщения молча переставали обрабатываться. Теперь бот в этом случае перезапускается |
| `Dockerfile` | Python 3.12 и часовой пояс МСК, чтобы сборка на хостинге была одинаковой |
| `/update` смотрит в **этот** репозиторий | Чтобы обновление не затирало твои правки кодом оригинала |
| `DATA_DIR` | Позволяет хранить настройки на постоянном диске, если хостинг его даёт |

---

## 1. Подготовка (5 минут)

1. **Токен бота.** В Telegram открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → скопируй токен вида `1234567890:AAH...`.
2. **Свой Telegram ID.** Напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число, например `123456789`.
3. **golden_key с FunPay.** Открой funpay.com в браузере (ты должен быть залогинен) → `F12` → **Application** → **Cookies** → `https://funpay.com` → строка `golden_key` → скопируй 32 символа.
   ⚠️ Никому его не показывай: это полный доступ к твоему аккаунту FunPay.

## 2. Создание бота на BotHost

1. Зарегистрируйся на bothost.ru и подключи GitHub (или укажи ссылку на репозиторий `https://github.com/dyukk-y/FunPAy`).
2. Создай нового бота:
   - **Язык / платформа:** Python
   - **Репозиторий:** `dyukk-y/FunPAy`, ветка `main`
   - **Файл запуска:** `main.py`. Если хостинг видит `Dockerfile`, он сам возьмёт команду оттуда.
   - **Версия Python** (если спросит): 3.11 или 3.12
3. В разделе **переменных окружения** (Environment / ENV) добавь:

   | Переменная | Значение | Обязательно? |
   |---|---|---|
   | `BOT_TOKEN` | токен от BotFather | ✅ да |
   | `ADMIN_IDS` | твой Telegram ID | ✅ да (с ним ты сразу админ) |
   | `ADMIN_PASSWORD` | любой пароль | желательно (нужен, чтобы войти с другого аккаунта TG) |
   | `GOLDEN_KEY` | golden_key с FunPay | желательно |
   | `FUNPAY_PROXY` | `login:pass@ip:port` | нет |
   | `USER_AGENT` | User-Agent твоего браузера ([whatsmyua.info](https://www.whatsmyua.info/)) | нет, но лучше задать |
   | `DATA_DIR` | путь к постоянному диску (см. п. 4) | если хостинг его даёт |

   Пример всех переменных лежит в файле `.env.example`.
   **Сам токен и ключ в репозиторий не коммить!** Их место только в панели хостинга.
4. Запусти бота. В логах должно появиться:
   ```
   [supervisor] Запуск бота ...
   Telegram-бот запущен: @твой_бот
   ```
5. Открой своего бота в Telegram → `/start` → `/menu`.
6. Добавь бота **администратором в свой канал** (права: публикация, редактирование, удаление) и нажми `/ads` → «🔄 Проверить канал».

## 3. ⚠️ Самое важное: чтобы бот не падал и ничего не терял

**1) Настройки хранятся в папке `data/`.** Это `config.json`, файлы ключей автовыдачи, аналитика.
На многих хостингах при каждом передеплое (новый `git push`, пересборка) папка проекта
создаётся заново, и **всё, что ты настроил через Telegram-меню, исчезает**.

Что с этим делать:
- Базовые вещи (токен, пароль, golden_key, прокси) задавай **переменными окружения**: они переживают любой передеплой.
- Если хостинг даёт **постоянное хранилище (volume / диск)**, укажи его путь в `DATA_DIR`
  (например `/data` или тот, что написан в панели). Бот сам сделает `data/` ссылкой туда.
- Делай бэкап командой `/export_settings` перед каждым обновлением кода.
- Не держи единственную копию ключей автовыдачи на хостинге, храни их и у себя.

**2) Перезапуски бот переживает сам.** Сторож в `main.py` перезапускает его после любого падения.
Если хостинг тоже умеет «перезапускать при падении» (auto-restart), включи и это: будет двойная страховка.

**3) Не меняй IP.** Если FunPay видит golden_key то с одного IP, то с другого, он может разлогинить.
Лучше всего, когда бот всегда ходит через один и тот же прокси (`FUNPAY_PROXY`).
Если сервер хостинга в РФ и Telegram оттуда не открывается, тоже нужен прокси.

**4) Коды выхода (если интересно, почему бот остановился):**
- `0`: ты сам выключил бота (`/power_off`). Сторож его не поднимает, запусти кнопкой в панели.
- `2`: бот не настроен (нет `BOT_TOKEN` / `ADMIN_PASSWORD`). Добавь переменные и перезапусти.
- остальные коды: падение, сторож перезапустит сам.

**5) Логи:** в панели хостинга, либо командой `/logs` прямо в Telegram.

## 📱 Управление с телефона

Всё ниже делается кнопками в Telegram, консоль и ПК не нужны. `/start` или `/menu` открывают меню.

### 🔑 Сменить golden_key (если FunPay разлогинил)
- **Самый быстрый способ:** просто пришли боту ключ (32 символа) одним сообщением. Бот спросит
  «Поставить его?», проверит ключ входом на FunPay и покажет ник аккаунта. Потом сохранит ключ,
  перезапустится и через ~10 секунд будет работать с новым ключом.
- Или через `/menu` → **🔑 Обновить golden_key**, или командой `/golden_key`.
- Сообщение с ключом бот сразу удаляет из чата.
- Если FunPay не подключился при запуске, бот сам пришлёт сообщение с кнопкой «🔑 Обновить golden_key».
- Ключ с телефона на Android: Firefox или Kiwi Browser + расширение **Cookie-Editor** → funpay.com → `golden_key`.
- Ключ, присланный в Telegram, **не затирается** старым `GOLDEN_KEY` из панели хостинга.
  Он заменится, только если ты впишешь в панель другое значение.
  ⚠️ Если хостинг стирает `data/` при пересборке (см. раздел 3), после пересборки снова возьмётся ключ
  из панели. Поэтому после смены ключа в Telegram лучше обновить его и в панели.

### 📝 Тексты и цены лотов (`/menu` → 📝 или команда `/lots`)

**Еженедельный счётчик.** В описании лота пишешь, например:
```
📅 Актуально на 06.04.2026, 04:00 МСК:
Мы уже успешно продали 532 рекламных размещений! 🚀
*(Данные обновляются каждую неделю для вашей уверенности)*
```
Раз в неделю (день и время выбираются кнопками, по МСК) бот во **всех** лотах с этим текстом:
- ставит сегодняшнюю дату и время;
- прибавляет к числу случайное от 3 до 10. Число одинаковое во всех лотах, диапазон меняется кнопкой «➕ Прибавка».

Как включить:
1. `/lots` → **👀 Предпросмотр**: бот покажет, какие лоты нашёл и что поменяет, ничего не сохраняя.
2. **🚀 Обновить сейчас**, если хочешь обновить прямо сейчас.
3. **🔴 Автообновление раз в неделю** → станет 🟢, и дальше бот всё делает сам.
   После каждого обновления присылает отчёт.

Полезное:
- **🔢 Число** — поставить своё число, например 600. Следующее обновление прибавит к нему 3–10.
- **✏️ Шаблон счётчика** — если в лотах другой текст. Скопируй кусок из лота и замени в нём дату на `{date}`,
  время на `{time}`, число на `{count}`. Эмодзи, звёздочки и переносы строк могут отличаться, бот смотрит на слова.
- Если бот перезапустился в момент обновления, число **не прибавится дважды**: лоты с сегодняшней датой пропускаются.
  Если бот был выключен во время запуска по расписанию, он догонит обновление в течение суток.

**🔁 Замена текста.** «Найти → заменить» во всех лотах. Перед заменой бот покажет предпросмотр,
потом можно выбрать «один раз» или «каждую неделю». Замены, которые повторяются каждую неделю, можно удалить из списка.

**💰 Изменить цены** для всех лотов, по ID или по слову в названии:
`150` (поставить), `+20`, `-20`, `+10%`, `-10%`. Сначала предпросмотр «было → стало», потом кнопка «Применить».
Быстро для одного лота: `/price 12345678 150` или `/price 12345678 -10%`.

**📦 Какие лоты.** Бот видит включённые лоты из профиля. Выключенные можно добавить по ID,
а лоты, которые трогать нельзя, исключить.

Защита: между сохранениями лотов пауза 2–5 сек (антибан). Ошибка на одном лоте не останавливает остальные.
После 5 ошибок подряд обновление аккуратно останавливается: обычно это значит, что FunPay разлогинил.
Тогда бот пришлёт отчёт, а ты обновишь golden_key.

### 📣 Реклама полностью автоматически (`/menu` → 📢 Реклама или `/ads`)

**Один раз:** добавь бота в свой канал (`-1002120185316`) **администратором** с правами
«Публикация сообщений», «Редактирование» и «Удаление». Потом нажми `/ads` → **🔄 Проверить канал**.
Если прав нет, бот сам напишет при запуске, чего не хватает. Пока прав нет, он работает в ручном режиме:
присылает карточку заказа, а ссылку на пост присылаешь ты.

Совет: если у канала нет публичной ссылки (@username), ссылки на посты вида `t.me/c/…` откроются только
у подписчиков. Бот предупредит об этом при проверке канала.

**Дальше всё происходит в чате FunPay без тебя:**

1. **Покупатель оплатил.** Бот пишет ему: «Спасибо за покупку! 🙌 Пришлите сюда, в этот чат, текст рекламного
   поста. Если к посту нужно фото — отправьте и его… Когда всё отправите, напишите «готово»».
   Тебе приходит одна карточка: лот, покупатель, сумма, срок и что сейчас происходит.
2. **Покупатель присылает текст и фото.** Можно несколькими сообщениями, фото до или после текста.
   - Если текст пришёл **до оплаты** («вот пост, сейчас оплачу») или покупатель пишет «я отправил выше»,
     бот сам найдёт его в истории чата.
   - Короткие вопросы («а когда выйдет?») в пост не попадают, на них отвечаешь ты.
3. **«готово».** Бот показывает в чате, как будет выглядеть пост, с фото и сроком: «Всё верно? «да» / «заново»».
   Если покупатель что-то дошлёт, предпросмотр обновится.
4. **«да».** Бот публикует пост в канал:
   - одно фото + текст до 1024 символов → фото с подписью;
   - фото + длинный текст → один пост, картинка над текстом;
   - несколько фото → альбом с подписью;
   - текст публикуется как есть, со всеми символами и эмодзи;
   - в лоте есть «закреп» → пост закрепляется без уведомления подписчикам;
   - формат «**1/24**» (1 час в топе / 24 часа в ленте) → пока пост в топе, следующий рекламный пост встаёт
     в очередь. Покупатель получает сообщение «будет опубликован сегодня в 15:00 по МСК»;
   - включены **тихие часы** → ночью бот не публикует, а ставит пост на утро.
5. **Сразу после публикации** покупатель получает в FunPay:
   «https://t.me/c/2120185316/123 — реклама в канале. Подтвердить лот можете сейчас или по истечении 24 часов.»
   Тебе приходит «📣 Опубликовано» с кнопками «📌 Закрепить / 📍 Открепить» и «🗑 Удалить пост».
6. **Когда срок закончился**, бот открепляет и удаляет пост и сообщает тебе.
   Для «навсегда» и «1/0» пост не удаляется.
7. **Покупатель подтвердил заказ.** Бот пишет «Был рад посотрудничать, будем ждать вас вновь! ❤️» и следующим
   сообщением «Если не тяжело, напишите отзыв пожалуйста о рекламе, нам важно ваше мнение 😉».

**Чтобы не было путаницы:**
- несколько заказов от одного покупателя бот собирает по очереди;
- если FunPay прислал сообщение дважды, бот учтёт его один раз;
- служебные слова «готово», «да», «заново» в пост не попадают.

**Если хостинг стирает `data/` при пересборке:** бот хранит резервную копию в твоём чате с ботом.
Это одно закреплённое сообщение-файл «💾 Резервная копия…», бот обновляет его сам. В копии лежат
заказы рекламы, база автоответов (с твоими правками) и все настройки, кроме токена бота.
После обновления бот всё восстановит и напишет «♻️ … восстановил из резервной копии».
**Не удаляй и не открепляй это сообщение.**

Очередь «топа» учитывает только рекламные посты, которые публикует сам бот. Свои посты в канал во время
чужого топа ты публикуешь на своё усмотрение.

**Если что-то пошло не так:**
- нет прав в канале или Telegram недоступен → покупатель получит «публикация немного задерживается»,
  ты — кнопки «🔁 Повторить» и «✍️ Опубликую сам»; бот сам повторит через 10 минут;
- молчит покупатель → бот один раз напомнит ему через час;
- бот перезапустился → всё продолжится с того же места.

Настройки в `/ads`:
- **проверка перед публикацией** — каждый пост сначала приходит тебе с кнопкой «✅ Опубликовать»;
- **удаление по сроку**;
- **тихие часы**;
- **подпись под постом** (например `#реклама`);
- **текст инструкции** для покупателя и **сообщение со ссылкой**.

### 🧠 Автоответы в твоём стиле (`/menu` → 🧠 Автоответы или `/sales`)

Бот учится на **твоих** ответах, но только в чатах, где покупатель написал первым:
- база ответов обновляется сама каждые 20 минут;
- **уверен** (вопрос очень похож на тот, на который ты уже отвечал) → отвечает сам, как ответил бы ты;
- **не уверен** → присылает тебе до 3 готовых вариантов, нажимаешь номер, и ответ уходит;
- ответы, которые ты дал 3 раза и больше, бот разрешает себе отправлять сам. Если выключишь «авто» у ответа
  вручную, бот больше не включит его сам;
- 🔒 ключи, логины, пароли и почты бот никогда не отправляет сам;
- не отвечает, если ты сам переписывался в этом чате последние 10 минут, и не больше 3 автоответов в чате за сутки;
- в чате, где покупатель присылает рекламный пост, автоответы молчат;
- первый раз нажми **📥 Изучить переписку**, чтобы бот прочитал старые чаты.

### 🔵 Онлайн и 📈 автоподнятие
Оба модуля включены по умолчанию.
- **Онлайн.** Бот постоянно опрашивает FunPay, раз в 5 минут проверяет, что аккаунт «в сети», и раз в 40 минут
  обновляет сессию FunPay. Раньше сессия со временем истекала, и бот «отваливался». Если FunPay разлогинил,
  придёт кнопка «🔑 Обновить golden_key».
- **Автоподнятие.** Лоты поднимаются, как только FunPay разрешает, по точному времени ожидания от самого FunPay.

## 🩺 Если бот упал или завис

Бот сам следит за своим здоровьем:
- **Завис** (не отвечает 3 минуты) — перезапускается сам и записывает, на какой строке кода застрял.
- **Упал** — сторож поднимает его через 5–120 секунд.
- **После любого аварийного перезапуска** присылает тебе в Telegram «⚠️ Бот перезапустился после сбоя»
  с причиной: зависание, ошибка, «убит системой — нехватка памяти» и т.п. В сообщении есть и расход памяти
  в момент сбоя (бот / весь контейнер / лимит тарифа).

Если приходит «нехватка памяти», нужен тариф с бо́льшим объёмом RAM. Бот занимает ~115–150 МБ, на тарифе
с 256 МБ это впритык.

## 4. Как менять бота под себя

Код твой, меняй что хочешь. Последовательность такая:

1. Поправь файлы прямо на GitHub (карандашик ✏️ на странице файла) или у себя на компьютере:
   ```bash
   git clone https://github.com/dyukk-y/FunPAy.git
   cd FunPAy
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   python main.py                # локально спросит токен в консоли или возьмёт его из переменных
   ```
2. Закоммить и запушь в ветку `main`: `git add . && git commit -m "что поменял" && git push`.
3. На BotHost нажми **«Пересобрать / Deploy»** (или включи автодеплой при пуше).

Где что лежит:
- `modules/`: вся логика (автовыдача `auto_delivery.py`, автоответы `auto_response.py`, автоподнятие `auto_lift.py`, ИИ `ai_assistant.py` …)
- `modules/lot_texts.py`: счётчик, замены текста, цены (логика); `bot/handlers/lot_texts.py`: его меню
- `modules/sales_brain.py` + `bot/handlers/sales_brain.py`: анализ переписки и автопродажи
- `bot/handlers/golden_key.py`: смена golden_key с телефона
- `bot/handlers/`: команды и меню Telegram
- `bot/keyboards.py`: кнопки
- `plugins_user/`: **самый безопасный способ** добавить своё. Пиши плагин по образцу `example_plugin.py`,
  тогда не придётся трогать основной код (см. раздел «Система плагинов» в README.md).

Перед пушем можно проверить, что ничего не сломано:
```bash
python -m compileall -q bot config core modules utils plugins FunPayAPI main.py
pytest tests/
```
Ошибку в синтаксисе тесты поймают сразу. Если её не заметить, бот на хостинге упадёт при старте,
сторож будет бесконечно его перезапускать, и в логах будет видно, в каком файле и строке проблема.

### Обновления от оригинального автора

Твой репозиторий хранит историю оригинала, поэтому новые версии PaltoFunPayBot можно забрать к себе:
```bash
git remote add upstream https://github.com/PaltoProjects/PaltoFunPayBot.git
git fetch upstream
git merge upstream/main     # при конфликтах git покажет, что поправить
git push
```
Команда `/update` в боте качает файлы из **этого** репозитория. На хостинге с автодеплоем
она не нужна: просто пушь в GitHub и пересобирай.
